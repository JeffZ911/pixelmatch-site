## Frequently Asked Questions

### What is the Universal Commerce Protocol (UCP) in Shopify Summer '26?
The UCP is a standardized data framework introduced in the Shopify Spring/Summer 2026 Edition that allows AI agents to communicate across different commerce platforms. It requires product images to have specific metadata and visual clarity so that AI shoppers can accurately "see" and compare products without human intervention.

### Why is 2048x2048 px the recommended size for Shopify?
Shopify recommends [2048 × 2048 pixels](https://help.shopify.com/en/manual/products/product-media/product-media-types#image-size-and-shape) because it provides the highest level of detail for the platform's zoom functionality while ensuring the image remains a perfect square. For AI visual search, this resolution provides enough "pixels of interest" for a neural network to identify small product details, like fabric texture or port placements.

### Can I use Photoroom for Amazon and Shopify simultaneously?
Yes, but you must be careful with background requirements. While Shopify's 2026 Edition favors AI-generated lifestyle backgrounds for discovery, Amazon requires a [pure white background](https://sellercentral.amazon.com/help/hub/reference/external/G1881) for the main image. You will need to run two separate batch processes or use a tool like PixelMatch that can toggle between "Marketplace White" and "AI Contextual" backgrounds in a single workflow.

### Does batch processing images affect my Shopify site speed?
The batch processing itself happens off-site, but the resulting files impact speed. To maintain high Core Web Vitals, ensure your AI tool exports in WebP format. Shopify's CDN automatically optimizes images, but starting with a file [under 500KB](https://help.shopify.com/en/manual/online-store/os/using-themes/change-the-layout/images) ensures that AI agents can crawl your site quickly, which is a ranking factor in agentic search.
